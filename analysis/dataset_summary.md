## Conclusion

The empirical benchmark dataset demonstrates tight physical coupling between CPU core frequency, SRAM capacity, and ML-KEM stack memory requirements. High-performance targets (e.g., Cortex-M7 @ 480 MHz) achieve sub-millisecond key generation but demand larger SRAM footprints (>= 28 KB for ML-KEM-1024), whereas ultra-low-power microcontrollers (e.g., Cortex-M0 @ 48 MHz with 16 KB SRAM) are strictly limited to ML-KEM-512 to prevent stack overflow Out-Of-Memory (OOM) failures. These empirical bounds provide robust feature distributions and boundary constraints to train the upcoming AI recommendation system for automated post-quantum IoT security variant selection.
